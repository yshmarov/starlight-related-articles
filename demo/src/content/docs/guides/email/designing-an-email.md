---
title: Designing an email
description: Lay out a message in the email editor.
---

The email editor composes messages from stacked blocks — text, image, button,
divider and spacer.

## Add blocks

Drag a block from the palette onto the canvas. Blocks stack vertically; there is
no free positioning, which keeps messages readable in clients that ignore CSS.

## Style a block

Select a block to edit its padding, background and typography. Styles set on the
message apply to every block that has not overridden them.

## Preview

Preview renders the message as a desktop and a mobile client would show it.
Always preview before sending: several popular clients strip background images
and collapse margins.
